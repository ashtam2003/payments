What is Stripe?

Stripe is a global payment processing platform that enables businesses to accept payments online, in-app, and in person. It provides APIs, dashboards, and financial tools for handling payments, subscriptions, invoicing, and more.

🔌 Core Role

  • Payment Gateway → securely collects payment details
  • Payment Processor → communicates with card networks and banks
  • Supports online, mobile, in-person, and marketplace payments

📌 What Stripe Includes

  • APIs for payments, billing, checkout, and customers
  • Dashboard for transactions, payouts, and reconciliation
  • Tools for fraud, tokenization, and subscription lifecycle
Stripe is more than a gateway.

It combines gateway capabilities with payment processing, hosted checkout, customer management, and subscription billing in one platform.

Modern payment flows

Stripe uses PaymentIntents for dynamic authentication, SetupIntents for card saving, and the Payment Element to reduce PCI burden while preserving flexibility.

Auth / Capture / Refund / Void

Auth

  • Create a PaymentIntent without capture
  • Reserve funds without charging immediately

Capture

  • Collect authorized funds later
  • Use payment_intent.capture

Refund

  • Refund full or partial payments
  • Use refunds endpoint

Void

  • Cancel before capture
  • Release authorization holds
PaymentMethods vs Tokens

Stripe typically uses PaymentMethods with tokenized data, so raw card details never hit your backend.

Webhooks and event callbacks

Stripe can notify your backend in real-time on events like payment_intent.succeeded, invoice.paid, and charge.failed so you can update order status immediately.

curl https://api.stripe.com/v1/payment_intents \
  -u sk_test_xxx: \
  -d amount=2000 \
  -d currency=usd \
  -d payment_method=pm_card_visa \
  -d confirm=true

Common Errors

Declines

  • Insufficient funds
  • Incorrect card details
  • Fraud blocks

Duplicate Transaction

  • Same PaymentIntent reused incorrectly
  • Use idempotency keys with repeated requests

Token Issues

  • Expired or invalid PaymentMethod
  • Use fresh tokens for each new checkout attempt

Settlement Mismatch

  • Timing differences between payments and payouts
  • Check payout reports, fees, and reserve holds
ACH Returns

Bank rejects payment after processing; common return codes include R01, R03, R10, and R29.
